# Collaboration logos

These unmodified vector assets identify institutions involved in the research.
The website links each mark to the institution's official website.

- `att.svg`: AT&T's logo, from the [Wikimedia Commons source file](https://commons.wikimedia.org/wiki/File:AT%26T_logo_2016.svg), which identifies AT&T as the author and [att.com](https://www.att.com/) as its source.
- `cornell.svg`: Cornell University's seal, downloaded from the university's [official red header logo](https://www.cornell.edu/assets/core/images/logo-red.svg).
- `universite-paris-cite.svg`: Université Paris Cité's logo, from the [Wikimedia Commons source file](https://commons.wikimedia.org/wiki/File:Logo_Universit%C3%A9_Paris-Cit%C3%A9_(partenariat_Wikim%C3%A9dia).svg), attributed to Graphéine and sourced to the university's [official logo artwork](https://u-paris.fr/wp-content/uploads/2022/03/UniversiteParisCite_logo_horizontal_couleur_RVB.pdf).
- `purdue.svg`: Purdue University's horizontal signature, downloaded from the [official Purdue website asset](https://www.purdue.edu/home/wp-content/themes/purdue-home-theme-beta/imgs/PU-H-light.svg).
